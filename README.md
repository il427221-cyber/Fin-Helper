# 📱 Финансовый Помощник

**Финансовый помощник** -это pet-проект, созданный для практического изучения Jetpack Compose, декларативного UI и обработки асинхронных вычислений с помощью Kotlin Coroutines.

---

## 🛠 Технический стек:
- UI: Jetpack Compose.
- Architecture: MVVM с четким разделением ответственности.
- Asynchrony & State: Kotlin Coroutines (`viewModelScope`), управление состоянием UI через `StateFlow`.
- Navigation: Jetpack Compose Navigation.
- Libraries: Capturable (для создания скриншотов экрана).

---

## 🚀 Возможности:
- Расчет налогов: НДФЛ, НДС, Налог на недвижимое имущество.
- Расчет финансовых показателей: ROI (окупаемость инвестиций), ROS (рентабельность продаж), расчет ежемесячного платежа по кредиту.
- Расчет суммы вклада: поддержка алгоритмов без капитализации, с ежегодной и ежемесячной капитализацией процентов.
- Экспорт результатов: создание скриншота вычислений с возможностью сохранения в галерею устройства или шеринга.

---

## 📈Технические вызовы и полученный опыт:
- Кастомизация UI-компонентов: Столкнулся со сложным поведением стандартных полей ввода при форматировании финансовых значений. Для решения задачи реализовал кастомную обертку над `BasicTextField` на базе `OutlinedTextField`, что позволило добиться нужного контроля над вводом данных.
- Работа с контекстом и Bitmap в Compose: Реализовал механику сохранения экрана в графический файл с помощью библиотеки `Capturable`. Разобрался с тем, как компоненты библиотеки взаимодействуют с UI  для создания скриншотов.
- Проектирование интерфейсов: На практике освоил построение стандартных UI-паттернов (TopAppBar, BottomAppBar) и организацию навигации между экранами в рамках Single Activity подхода на Compose Navigation.
- Оптимизация потоков :Закрепил навыки работы с асинхронным кодом. Понял, как правильно делегировать тяжелые математические расчеты в фоновые потоки через `viewModelScope`, чтобы избегать блокировки UI-потока и обеспечивать плавность интерфейса.
