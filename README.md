Проект: Финансовый помощник

Описание: Данное мини-приложение является полезным инструментом для повседневных задач, связанных с различными финансовыми расчетами.
Целевой аудиторией могут выступать бухгалтеры, экономисты, представители бизнеса, а также все люди, которые хотят быть более подкованными в финансовых инструментах.

Возможности:
Расчет налогов (НДФЛ, НДС, Налог на недвижимое имущество).
Расчет финансовых показателей (ROI (окупаемость инвестиций), ROS (рентабельность продаж), Расчет ежемесячного платежа по кредиту).

Расчет суммы вклада (без капитализации, с ежегодной капитализацией (банк начисляет проценты раз в год и добавляет их к вкладу), 
с ежемесячной капитализацией (банк начисляет проценты раз в месяц и добавляет их к вкладу).
Создание скриншота вычислений (можно сохранить его в галерею или с кем-нибудь поделиться).

Технологии: Проект написан полностью на Kotlin на Jetpack Compose с использованием структуры MVVM. Все вычисления делаются в корутинах.
Данные помещены в data-классы. Есть навигация между экранами. Используются 2 вьюмодели и 2 репозитория.
